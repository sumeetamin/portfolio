# Sumeet Amin — Portfolio

A responsive, static portfolio focused on data science, applied machine learning, and AI evaluation. It uses semantic HTML and inline CSS, has no runtime framework or external JavaScript, and is hosted with GitHub Pages.

## Live site

[Open the portfolio](https://sumeetamin.github.io/portfolio/). GitHub Pages publishes from the `main` branch root; commits to `main` trigger a Pages build.

## Featured work

The homepage summarizes six public projects with benchmark metrics and scope limits: fraud scoring, retail demand planning, credit-default analysis, LLM evaluation, churn prioritization, and turbofan remaining useful life.

## Accuracy and scope

All reported numbers are tied to a specific public-data or local benchmark and are labeled with their limitations. The projects are portfolio prototypes; the site does not claim client outcomes, production adoption, or seniority. See each repository for data provenance, methodology, and full results.
